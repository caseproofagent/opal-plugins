# opal-plugins

Opal's plugin bundles for the Claude and ChatGPT directory submissions.

This repository holds plugin files only: manifests, icons and the bundle metadata each directory asks for. It holds no secrets, keys or credentials.

Opal's MCP server is not here. It lives in [caseproofagent/myopal](https://github.com/caseproofagent/myopal), and the bundles in this repository point at it.
